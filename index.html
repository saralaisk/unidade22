O que aprendemos?

🔐

Criptografia

É uma técnica que transforma informações em dados protegidos, permitindo que somente pessoas autorizadas tenham acesso ao conteúdo.

#️⃣

Hash

É uma função que transforma dados em uma sequência de caracteres de tamanho definido. É utilizada para verificar a integridade das informações.

🛡️

Segurança

Essas tecnologias ajudam a proteger informações pessoais, arquivos e comunicações digitais.
